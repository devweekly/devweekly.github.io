# 回归对照：第十三章 茱蒂与夜

用原文已有的一章做盲写，再拿成稿和原文逐项比节奏。做法是 `npm run dev -- regress --chapter 13`：写作 Agent 只看得到前 90 行原文、本章任务和风格文档，看不到原文任何一句；两版各写一次，各修订一次；最后由另一个模型的评审 Agent 对照原文判断。

| 角色 | 模型 | 配置 |
|---|---|---|
| 写作 | `deepseek-v4.1-flash` | A：思考关闭 / low；B：思考 adaptive / high |
| 评审 | `glm-5.3-flash` | 思考 adaptive / high |

目标章：卷 1 第十三章，L2057–L2317，原文 2730 汉字、159 句、131 段。章节任务由人工写成一段白描，不含原文句子。

## 指标对照

| 指标 | 原文 | A（思考关闭） | B（adaptive/high） |
|---|---:|---:|---:|
| 汉字数 | 2730 | 2484 | 2195 |
| 平均句长 | 17.2 | 19.7 | 18.1 |
| 句长 p90 | 40 | 44 | 39 |
| 短句占比（≤10） | 40.3% | 41.3% | 41.3% |
| 长句占比（≥31） | 17.6% | 26.2% | 21.5% |
| 对白行占比 | 46.6% | 56.6% | 51.9% |
| 段均句数 | 1.21 | 1.66 | 1.53 |
| 段均字数 | 20.8 | 32.7 | 27.8 |
| 强调标点每千字 | 20.1 | 5.2 | 17.8 |
| 加权节奏偏差 | — | 40% | 12% |

A 是修订后的数值；修订前平均句长 16.9、长句 17.0%、强调标点 1.6，偏差 20%。修订把它改坏到 40%：它把「一句一段」并成复句，段均句数从 1.5 升到 1.66，方向与原文相反。B 从 30% 修到 12%，句长中位数差 0、p90 差 −1、超长句差 0，只剩段落组织与总量（少 20% 字）偏离。

## 判断

- 急促感的来源不是句长本身。A 修订前的平均句长 16.9 已经贴着原文的 17.2，真正缺的是标点语气（1.6 vs 20.1 每千字）、单句成段的拍子（1.5 vs 1.21）和克制的逗号（1.79 vs 1.01）。
- 长句不是越多越好。A 修订后长句到 26.2%，比原文的 17.6% 还高，读起来仍然不像——长句靠并列景物撑长度，没有原文那种因果与推理链的信息层。
- 推理强度影响修订精度，不是充分条件。B 在同一份修订指令下把偏差从 30% 压到 12%，A 反而扩大；同一条指令，执行质量取决于模型对「段落即一拍」的理解。
- 评审 Agent 给的结论是 B 更接近原文，并把差异归到段落切分与标点习惯，而不是词汇或题材。

## 由此改掉的代码

- 修订加了采纳判定：偏差没有下降就退回原稿，避免把稿子改坏。
- 正文阶段默认从「思考关闭 / low」改为 `adaptive / medium`；`novel-generation.config.json` 可继续覆盖。
- 节奏硬约束换成这批实测数值：句均逗号 ≤1.2、段均句数 1.2–1.4、问号感叹号每千字 15–25、每 300 字一处 45 字以上且含两层信息的叙述句。

## 一次失败记录

首轮 B 的输出为 0 汉字：开启思考后，CLI 的默认 Agent 人格去调用被禁用的工具，把工具调用语法（`DSML` 标记）当成正文吐出来。修复是给纯文本调用注入专用 system prompt，并在调用层检测这类输出、命中后关掉思考重试。该轮未归档，结论记在这里。

复跑：`npm run dev -- regress --world conghuoniao --chapter 13 --model deepseek-v4.1-flash --review-model glm-5.3-flash`。原始章节与两版成稿在 `.output/regression/<run-id>/`，不入库。

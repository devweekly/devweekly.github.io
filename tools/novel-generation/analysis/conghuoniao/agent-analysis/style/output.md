- 他人视角起笔时主角姓名与归属延后；脱离人物的概括句须同段内被感知或记忆回收，否则按说明段处理。

- 动作段按动作转折或单字回应拆段，单段不混规则；动机推断只放在交涉、停顿处。
- 面板用第二人称、字段、编号、括号数值与代价条款，置于场景前或动作因果节点后；结算以固定报告标记引出，先意象后数字，末尾接回人物。
- 场景沿单一人物视线推进，用感官锚点收束并转入信息段；史实说明与情节分段。
- 跨卷变化只由题材器物承载，叙述机制保持一致；章末不复用同一悬念句式。

# 《从姑获鸟开始》世界参考（初始整理版）

> 本文件是辅助创作的高层设定索引，不是原著全文、官方设定集或完整正史。具体内容以合法取得的原著文本及可靠资料为准。新增内容必须标记为项目原创。

## 作品识别

- 作品：《从姑获鸟开始》
- 作者：活儿该
- 核心主角：李阎
- 核心结构：以阎浮果实连接多个具有独立历史、地理、社会结构和超凡规则的世界。

## 世界观骨架

### 阎浮与果实

阎浮体系包含多个世界。果实可视为相对独立的世界单元，各自拥有时代背景、社会秩序、超凡力量和特定冲突。不同世界并非简单换地图；当地历史、文化、资源和规则会影响人物选择及事件结果。

### 阎浮行走

阎浮行走是跨越不同世界、参与其中事件的特殊身份。跨世界经历带来能力、资源和认知变化，也意味着行动受到各自世界规则及更高层秩序的约束。

### 传承与能力

作品设有多层次的传承分类和能力体系。创作时应把能力视为有来源、有条件、有代价的规则，不要将其写成无边界的万能技能。未从可靠资料确认的具体等级、效果、限制和归属，列为待核实项。

## 已知故事空间（概览，非完整目录）

公开作品资料可见的故事空间涉及近现代城市与帮会、历史时期的江湖和战争、鬼怪与民俗交织的城市、南洋及其法术传统，以及末世废土等不同类型。它们的差异应体现在制度、生活细节、信仰、技术、战斗方式和人物生存策略上。

| 故事空间类型 | 可用于创作的环境维度 | 写作时需要核实 |
|---|---|---|
| 近现代港岛江湖 | 城市街区、帮会秩序、实战搏击、现代社会关系 | 具体年代、组织、人物与事件 |
| 历史时期的江湖 | 王朝制度、地方势力、军政关系、武术与民俗 | 历史节点、地理、官制和传承 |
| 鬼怪都市 | 日常城市与异常规则并存、夜间秩序、地方传说 | 具体规则、鬼怪能力和触发条件 |
| 南洋异闻 | 多元信仰、地方社会、法术传统与技术 | 地域文化、仪式细节及其来源 |
| 末世废土 | 资源稀缺、秩序重建、环境风险、身体改造 | 世界纪年、灾变原因和技术边界 |

## 原创衍生故事的使用原则

1. 优先设计原著未展开的普通人、地方组织、边缘职业和局部事件，避免依赖原著主角出场推动剧情。
2. 新故事可以与既有世界发生弱关联，但必须明确标注时间、地点和关联依据。
3. 如果使用原著角色，先核实角色在对应时间点的状态、能力和已知经历。
4. 每个新世界或新规则都要记录来源：原著明确、用户提供、公开资料推断、项目原创四类不可混淆。
5. 不直接导入或存储未经授权的整本小说、付费章节或抓取站点内容。

## 待核实资料

- 阎浮各层级及其完整规则、组织关系和历史沿革。
- 传承体系的正式分类、能力约束和相互关系。
- 各果实的准确纪年、地理、社会结构和进入/离开条件。
- 主要角色在不同时间点的经历、关系及能力变化。
- 原著各卷之间的时间线与关键事件因果。

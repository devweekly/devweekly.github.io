# 阎浮体系规则表

规则条目按「原文行号 → 规则内容 → 证据等级」整理，供写作时核对边界。等级含义见 `world-bible.md` 开头。行号指向 `original.txt`。

## 1. 果实与编址

果实的正式编址由类别、干支、序号组成，例如 `天·甲子九`、`地·甲子二百五十九`、`鳞·丁寅二十四`、`神·甲子九百八十四`、`羽·丙子一百二十八`（L10659–L10663、L17785、L84968 附近）。摘取者或完成事件者可给果实另起一个名字，形成「编号（名字）」并用的写法，如「鳞·丁寅二十四（太岁）果实」「地·甲子二百五十九（茱蒂）果实」（L44630、L44632）。序号越靠前，果实疆域和蕴含能量越大；`天·甲子九` 是已知唯一产出阎浮行走的果实（L45301–L45303，人物推断）。

| 状态 | 原文表现 | 证据 |
|---|---|---|
| 事件进行中 | 果实标注「阎浮事件进行中」，行走可出入 | L10663，原著明确 |
| 通行锁定 | 权限被具名行走锁定，所有行走无法进出 | L10673–L10675，原著明确 |
| 摘取 | 事件完成者获得再次进入权，果实可被命名 | L44851、L16392，原著明确 |
| 脱落 | 果肉被剥离、只余果核，事件记录可能丢失 | L26044、L110676，原著明确 |
| 指定进入 | 用道具指定果实，风险与结算收益同时提高 | L47252–L47258，原著明确 |
| 无实体忍土 | 已被摘取的果实不再配置实体忍土，行走突兀降临 | L47274–L47280，原著明确 |

果实的差异不只在布景。卷 3 的 `鳞·丁寅二十四` 里，得到朝廷正式册封即可获得能突破传承觉醒度瓶颈的「龙虎气」（L10695，探索笔记中的匿名记录，人物推断）；卷 13 的 `羽·丙子一百二十八` 序列与强度都低，当地人身体素质偏弱，可依赖的是蒸汽战争警备力量（L84968，人物推断）。写作时若把某个果实的技术、信仰或武力水平移植到另一个果实，需要标明依据。

## 2. 行走之间的关系

作者单章 L12187「本书力量体系和身份划分」给出事件内可能存在的三种关系，以及普通行走、代行者、脱落者的划分。这些是设定说明，不是某个人物的猜测。

| 关系 | 结算后果 | 证据 |
|---|---|---|
| 同行者 | 目标一致但可能有利害冲突；杀死同行者无奖励 | L12193–L12195，作者设定 |
| 与共者 | 利害关系完全一致；并肩作战时基础素质上升 30%，与传承加成相加；一方死亡，其余与共者所有传承觉醒度强制下降 10%，扣 5000 点 | L12197–L12201，作者设定 |
| 猎食者 / 被猎食者 | 猎食者杀死对方百分之百吞噬传承并获高额觉醒度奖励；被猎食者反杀可获对方 30% 购买权限，并有一定概率吞噬传承 | L12203–L12205，作者设定 |

代行者经特殊阎浮事件取得异兽称号，权限高于普通行走，职责近似管理员，彼此实力差距可以很大；貘是其一（L12209–L12211）。竞争代行者称号的门槛是经历六次阎浮事件，或某一传承复苏程度达到 100%（L7889、L12213）。脱落者背弃南阎浮提，在果实之间游走，受全体行走追杀，太岁是其例（L12217）。十一个代行者的说法出现在 L8115，但正文未列出完整名单（待核实）。

## 3. 事件流程与结算

事件开启时可献祭阎浮信物换取更高身份，或用信物替换本次事件（L8142–L8146）。事件期间，阎浮提供随身忍土做提示，低位行走与忍土的自由对话有字数限制，超出口径后只保留最基本提示（L33574–L33594）。完成度按世界观探索度衡量，60% 以上解锁其他行走对该果实的探索笔记，未达门槛时只能看到自己的记录（L10645、L10671）。

评价分六档：大吉、上吉、下吉、上上、中平、下下（L7209）。结算报告把点数和购买权限分开计算，点数按「基础值 × 评价加成」给出，权限按行为分项累加。

| 项目 | 已确认的数值或构成 | 证据 |
|---|---|---|
| 上吉点数 | 500 点（基础 200 点加成 150%）；推算大吉为 600 点（基础加成 200%） | L7317、L7589、L16100，原著明确 |
| 大吉点数 | 600 点（基础 200 点加成 200%） | L16100、L81490，原著明确 |
| 购买权限 | 195% = 个人行动 76% + 全额完成事件 30% + 三张残篇 30% + 杀死猎食者 59%；贡献残余物再升 10% 至 200% 峰值 | L7319–L7329，原著明确 |
| 登顶结算 | 权限额度 250% | L81492，原著明确 |
| 附带权利 | 大吉评价获得一次再次进入该果实的权利 | L16392，原著明确 |
| 特殊奖励 | 按事件内容抽取对应力量物品，首事件强制认定为不可交易传承 | L7333–L7335，原著明确 |

阎浮点数既能按次使用技能（每次 1 点），也能买断技能（10 点，L707）；还能购买物品、专精和信息，贵重物在确认拥有权后可折算点数（L512、L695）。结算奖励的一部分并非果实中原有的实物，而是击杀强敌后产生的「果实养料」由阎浮转化而成（L81729）；世分清浊二气，清者为树育之精，浊者为养实之料（L81739，人物推断，专属忍土转述十主内部刊物）。

## 4. 能力结构

行走的个人信息分为专精、状态、技能、传承四栏（L7863）。卷 9 开篇把实际战力归为三部分，其中专精与自悟技能被看作决定上限发挥的一层（L47190–L47198，人物推断）。

| 层次 | 获取与性质 | 代表 |
|---|---|---|
| 传承 | 事件特殊奖励、卷轴或吞噬获得；有复苏/觉醒度，决定非凡的类别 | 姑获鸟之灵·钩星、饕餮之心·食技、开明兽之传承·怒灵（L7341、L18119、L3474） |
| 四格拓展技能 | 花点数学习，上下限固定；更像阎浮授予的权限，可被收回 | 惊鸿一瞥、黄巾符咒（L7871） |
| 专精与自悟技能 | 靠练与悟，阎浮无法代为突破；不可量化 | 古武术专精、虎挑、燕穿帘、龙拗首、枪剑七大行（L14857、L84198） |

貘用祸斗与阳火咒说明前两者的差别：技能只给一道火咒，传承给的是火焰本身，是「超脱凡物的钥匙」（L7883）。传承有十类，天地人神鬼为五仙、倮鳞羽毛介为五虫；十类皆以「灵」为尊，异兽之灵万不存一（L16530、L23821）。五虫走个人能力路线、五仙偏经营势力只是李阎的猜想，原文随即注明「当然，这只是李阎的想法」（L16530–L16541），不能当定论。

觉醒度既是成长刻度也是位阶门槛。散阶升十都需要任一传承觉醒度 39% 并完成一次上吉事件，九曜 69%，八极 99%（L28138–L28140）。位阶共九级四层：散阶 / 十都·九曜·八极 / 七宫·六司 / 五方老·四御·三清（L28122–L28130）。七宫的基本条件是成为代行者，五方老可自由穿行已知所有果实而不必完成事件（L28142–L28148）。位阶由代行者专门评定，评价越高权限越大，事件也越危险（L12219–L12225，作者设定）。

## 5. 组织与秩序

十主掌握规则修订权。普通行走的结算奖励细则由鬼主刘大均草拟、全体十主修订通过，持异议者可在阎昭会以十主权力发起重新决议（L81731）。阎昭会会场勾连阎浮果树主干，含雷池与母冠，母冠存放高级内参资料（L98773、L99099）。阎昭会在各果实设有掩护机构，中兴保德国际拍卖有限公司即其一，前台「忍一」离果实后序号会重新分配（L99665）。

思凡设八苦：生、老、病、死、忧悲恼、恨别离、怨憎会、求不得（L26008）。其力量可剥离果实果肉、只留阎浮果核，果核的稀有程度被形容为百件传说级异物之和（L26050）。对阎浮而言，肆意剥离果肉的思凡是「最大的害虫」（L26471）。思凡与十主都是「实实在在的桂冠和力量」，不是虚名（L26012）。

忍土属于阎浮果树本体，只有拟态意识（L33578）。行走回归后，阎浮派忍土扮成其模样，维持果实内的身份与日常，为下次降临留出位置；若行走取得随时进入该果实的权限，就要自己穿梭两界维持关系（L44630–L44642）。完成终极阎浮事件会获得「阎浮的瞩目」并指派专属忍土，专属忍土可解答部分规则问题，但权限之外的问题会拒绝回答（L81480、L81743、L33590）。

## 6. 现实约束

貘转述给新行走的规矩共四条：行走之间的恩怨只能在阎浮事件中解决，不得在现实中干预其他行走的生活；不得透露阎浮事件的任何信息；尽量不在现实使用传承和明显不属于这个世界的能力与器物，必要时可自卫但会接受审查；阎浮事件每两个月开启一次，冥想即可回到那间房间（L7919）。违反这些约束的后果在正文中没有统一说明（待核实）。

## 7. 未闭合的问题

`鳞·丁寅二十四` 与 `鳞·丁酉二十四` 在卷 11 中各自出现 7 次和 5 次，指向同一果实还是两个相邻果实，本地全文没有明确交代；卷 11 末的摘取事件回退到「丁寅」（L80901），卷 12 的封闭说明又用「丁酉」（L81604），同一卷内两种写法并存。「脱落」在卷 5 指思凡剥离果肉、只余果核（L26044），卷 14 至卷 16 对 `地·甲子二百五十九` 写的却是自然腐烂、质量超出界限与根茎通道关闭（L98631、L106382、L110676），两套说法是否同一机制没有衔接。三清、四御的评定条件，十主完整名单，十类传承各自的边界，评价六档中点数的完整换算表，都未在现有文本中给出。模型抽取式标注尚未跑通全量，逐片段的实体、事件、关系候选仍为空，`worlds/<world>/library/annotations.json` 当前不存在。

# 小说叙事风格参考

本文件是写作参考，不是格式规范、评分表或验收清单。它记录从语料中观察到的倾向，供模型理解作品的叙事气质；具体章节首先服从人物、情境、情绪和故事本身。宁可写出自然、有感染力、人物鲜活的文字，也不要为了符合任何风格描述而牺牲小说性。不粘贴原文，不把某位作者的标志性句子、独特比喻或可识别表达作为模仿对象。配置约束的是叙述方式，不是情节和设定；设定核对以 `world-bible.md`、`yanfu-system.md` 为准。

## 首要原则：先写活小说

- 人物、欲望、冲突、行动、情绪和读者体验高于风格统计、设定说明和分析完整度。
- 风格描述是倾向，不是必须逐条命中的规则。场景需要时，可以改变句长、叙述距离、段落长度、对白密度和节奏。
- 不要把小说写成世界观讲解、人物档案、事件报告、推理报告或游戏任务复盘。设定只在人物遇到它、使用它、误解它或为它付出代价时进入正文。
- 不要求每个场景都承担主线推进、伏笔、人物弧光和信息揭示。允许闲谈、误会、犹豫、闲笔、生活细节、幽默、无用但迷人的观察；只要它们让人物和世界变得可信。
- 不要为了让人物变化“有证据”而在正文解释动机。人物可以矛盾、冲动、犯错、嘴硬、临时改变主意；让读者从行为和后果中感受，不要写成心理学案例。
- 惊喜、反转、浪漫、荒诞、残酷和偶然性都属于小说。不要因为事先无法从状态表推导，就自动压制它们。

## 叙事视角

- 默认视角：第三人称限知，贴近当前场景中的单一人物，跟随其感知与判断。
- 视角切换规则：以章节或场景为界切换。新卷常从另一个人物的处境起笔，先展示局部事实，再让主角进入该场景；同一场景内不随意跳进他人内心。
- 叙述距离：动作与对白贴近人物，环境铺陈可拉到中距离；偶尔用不带人物归属的概括句交代时代和秩序，但不发展成全知评论。概括句有的由「以前听人说过」一类措辞收回人物感知，有的保持为独立说明段或评断，两种处理分开检查。

## 语言节奏

句长和段落组织会随场景、人物、情绪与叙事距离自然变化。相关语料统计只保留在离线分析文件中，不注入正式写作提示，不进入章节验收或自动修订。不得为了接近某种统计分布而硬加长句、拆并段落或改变人物说话方式。

- 句长没有统一标准。交锋可以急促，推演可以绵密，闲谈可以松散；不追求某种固定分布。
- 段落随叙事呼吸。单句成段、长段铺陈、连续对白和突然断行都可以使用，取决于阅读时的停顿、情绪和画面，不套固定比例。
- 逗号要克制：避免无功能的并列和拖长，但句均逗号数量不设硬上限。长句的长度来自因果与推理链，不来自景物并列。
- 标点承担语气：问号与感叹号集中用于质问、反驳和失态的对白；按人物情绪和场景需要使用，不按每千字配额补标点。
- 长句形态：推理、交涉、观察和因果链复杂时允许出现含多层信息的长句；动作转折和情绪落点可以用短句。不得为达到固定频率硬加长句。
- 对白信息量：关键人物需要表达复杂立场时允许长段对白；寡言、戒备、失态或关系紧张时，短句和停顿同样合理。避免机械要求每个人物都说长段自述。
- 轻重缓急：放慢靠长对白、清单、推断段与有意的冗余；加快靠短句、单字回应、动作转折与跳切。章节应有符合事件发展的节奏变化，但不要求每章机械安排固定数量的快慢段。
- 人物语气靠句式长度区分：饶舌者给长句与自问自答，寡言者给短句与停顿。

## 场景表达

- 动作、环境与心理描写：根据人物和场景自由调节。可以用动作暗示心理，也可以深入内心；不规定哪一种描写必须占多数。
- 打斗/调查/日常场景的节奏差异：打斗靠招式、身体受力与结果连续推进，中间不插入解释；调查靠线索与对话逐层给出；日常场景放慢，用器物、物价、天气和气味建立年代与地点。
- 感官细节的使用原则：优先气味、声音、温度和材质，每场选少量具体锚点，不堆叠形容词。时代物只用于定位，不铺成清单。
- 系统面板与结算文本是两种体裁：面板用字段、编号、括号数值和罚则，可嵌在动作因果之后；结算以固定提示开头，先意象蒙太奇后数字报告，末尾落回人物反应。不把两者笼统并成「信息分散」。
- 跨卷差异主要由题材器物、行话和史实说明段承载；限知视角、卷首起笔节奏、字段化面板等叙述机制保持一致。史实说明段与情节叙述分段。

## 人物对白

- 不同身份/性格的语言区分：靠称谓、行话、句式长度和回避方式区分。军伍、帮会、国术、商人和官僚各有可辨认的用语边界；方言只作点缀，不影响理解。
- 潜台词与直接说明的比例：交锋场景以潜台词为主，人物常借问答试探对方的信息边界；规则说明允许直接，但尽量放进对话、系统提示或书面材料，不由旁白一次性讲完。
- 禁止出现的现代口吻或套话：历史与异域场景中不出现当代网络用语、管理术语和解释性旁白；不让人物替读者复述已经发生的事。

## 悬念与信息控制

- 信息揭示节奏：先给现象和后果，规则随后由事件结果、他人证词或结算报告补上。设定分散在对话、面板、探索笔记和书面材料里，不集中成设定讲座。
- 伏笔的埋设与回收方式：以物件、称谓、未解释的异常和人物承诺埋线，跨卷回收时标明时间跨度；回收前不反复提示，回收后交代代价。
- 章节结尾偏好的状态：以动作未完成、判断被推翻或新信息抵达为主，允许暂时收束，但不把每章都写成同一个悬念句式。

## 明确避免

- 模板化排比和重复总结：不在节末用对称句重述已发生的事。
- 解释性旁白过量：规则由事件证明，不由旁白担保。
- 所有角色使用相同语气：不同身份的知识边界和说话成本要能区分。
- 为制造反转而破坏人物动机或既有事实：新揭示只能补充未知信息，不能推翻已确认的结算结果、能力代价和时间线。
- 复刻原句、独特比喻或方言密度：这是风格禁区，不属于可学习的抽象特征。


## 创作优先级与使用边界

1. **文学效果第一**：语言是否自然、有画面、有情绪、有节奏，人物是否像活人，读者是否愿意往下读。
2. **故事成立第二**：人物行动有其处境和欲望，事件能产生后果，场景之间有吸引人的因果或情绪连接。
3. **连续性保护第三**：只防止明确的事实冲突、时间地点错误、人物不可能知道的信息、能力规则被无意破坏，以及会让读者无法理解的关键断裂。
4. **风格统计最后**：只用于离线诊断和模型实验。任何数字都不能要求正文改写。

不要将“人物选择有铺垫”误解为“人物必须按画像行事”；不要将“因果成立”误解为“所有事情都必须被解释”；不要将“信息控制”误解为“每个细节都必须服务伏笔”。小说允许留白、偶然、误判、无解和不可靠叙述。

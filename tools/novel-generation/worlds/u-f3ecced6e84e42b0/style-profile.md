# Style Profile

## 一、全局叙事气质

这套文本的叙事气质可以概括为**市井江湖的粗粝抒情**：描写对象是底层空间、边缘行当和以命相搏的人，语言本身却不粗糙，反而在关键处显出讲究和节制。叙述者不急着解释世界，先让人物站在一个具体地方，让读者从气味、声音、旧物和对话里自己摸清这是什么时候、什么地方。作者对人物有感情，但很少替人物抒情，情绪多半落在动作、停顿和没说出口的话上。信息给得克制，偶尔干脆留白，让读者自己补上。

最重要的抽象特征：

1. **先空间，后人物，再事件。** 文本常以一个具体地点开场：县城夜市、旧音像店、公寓床沿、被水淹的街。人物进入空间，空间反过来限定人物。地点不是背景板，它承担阶层、年代和命运的信息。

2. **白描优先于评价。** 叙述者大量给出可感知的细节，例如油光满面的摊主、发潮的电视、音像店柜里的旧唱片海报、雨水没过腰的街；情绪和判断往往只留一句极短的概括，或者干脆不写。

3. **对话是主要的情节推进器。** 大量关键信息、人物立场、关系张力和权力落差都发生在对话里；叙述者的任务是把对话周围的姿态、停顿和视线写准。

4. **克制与锋利交替。** 大部分叙述平实、耐心，句子偏长，带口语和方言成分；一旦进入冲突或转折，句子突然缩短，动作密度上升，往往只用一两句完成暴力或死亡。

5. **人物声音按阶层、地域和经验分层。** 说话方式承担身份信息：本地帮派人物用粤语混杂，主角用北方口语，文化人用书面语，底层人物更碎、更直。作者不靠固定口头禅区分人物，靠的是用词范围、句法完整度和说话时敢不敢停顿。

6. **情绪通过动作和留白抵达。** 悲伤不直说，写放下暖壶、手稳、水没洒；愤怒不直说，写把杯里的水饮尽、把玩杯子；决断不直说，写人物把子弹一颗颗压进枪膛，同时接着电话。

7. **神秘与日常同处一个平面。** 神异设定、怪谈残篇、超自然力量与旧唱片、爱立信手机、茶餐厅、便利店式交易并置，不用两套语气。超自然不被特殊修辞抬高，日常也不被降低。

8. **叙述者对人物有偏爱但不辩护。** 主角的狠、病、算计和动摇都被照实写出，叙述者不替他找理由，也不用旁白替他定性。人物做过的选择由后果自己说话。

## 二、叙述层面

**视角。** 第三人称限知为主，视点主要贴着主角，偶尔短暂滑到配角身上，用于交代主角不在场的信息，例如帮派头目密谈、敌方布置。视点切换一般用空行或场景断句隔开，不用“与此同时”这类过渡。视点流动时不解释谁知道什么，读者从上下文推断。

**叙述距离。** 多数时候是中等距离：能看见人物表情、动作、环境细节，但不进入长段心理。距离会在两种情况下收紧：一是人物正在做一件需要专注的事，例如拆残片、压子弹、摆架势；二是人物遭遇冲击的瞬间，例如看到变形的脸。这两种情况下，句子变短，感官细节变密，判断性词语消失。反过来，叙述者交代背景、解释设定、回顾若干天的事情时，距离拉开，语言更接近概述，句子也更长。

**节奏。** 整体是“慢—快—停”的结构：铺垫段落耐心、信息密度低但质感厚；冲突段落句子短、动作多；冲突结束后常有一个短停顿，由一个动作或一句独白收住，例如喝完水、笑一声、蹲在角落抽烟。文本不追求每段都推进，允许用不推动情节的段落建立气氛。

**句法。** 以短句和中长句交错为主，长句多用于描述环境和交代背景，短句多用于动作和情绪落点。口语成分明显，有方言词、俚语、语气词。偶尔出现不完整的句子，例如只有一个名词或一个动作，用于制造停顿感。不与语法规范较劲，但也不刻意破碎。

**段落。** 段落偏短，常见一两个句子成段，用于节奏控制和视觉留白。长段多出现在设定说明、背景回顾和一段连续的对话之后。场景转换用空行或独立短句，例如一个地名或一个时间标记，不用过渡句。

**信息揭示。** 倾向于延迟解释。新概念、新人物、新规则先出现、先被使用，读者从上下文推断；解释放在人物主动提问或情节需要时，而且解释往往不完整，保留未解部分。人物背景也常以他人视角带出，例如家中合照、长辈评价，不靠人物自述。

## 三、场景级风格差异

**对白场景。** 这是样本中最充分、最稳定的类型。特征：对话密度高，叙述只穿插必要姿态；说话人不一定轮流整齐，允许打断、答非所问、沉默以对；权力关系通过谁先开口、谁被允许沉默、谁在解释来体现；重要信息常由弱势一方说出，强势一方只用短句回应。对话结束后常有一句短叙述收尾，例如一个动作或一句自嘲，不让场景直接断掉。

**动作与打斗。** 样本中的打斗多写结果和瞬间，少写过程拆解。常见处理：用一两句写出兵器、距离、发力方式，然后直接给结果；旁观者视角描写打斗，主角视角只保留判断和感受；暴力发生后不渲染痛感，转向现场状态，例如血泡、积水、尸体位置。不追求招式详细展示，追求“谁更狠、谁更快、谁在赌命”的信息。

**群像与帮派场景。** 样本支持。特征是：以少数核心人物为锚，其余人物用一两个外观或身份特征标记，例如黄毛、红背心、马尾；群体意见通过一两个人代表表达；场面描写注意空间层次，例如二楼、帘子后、看台、门口；群像里的沉默和眼神常比台词重要。

**内心独白。** 样本中以短促、带自嘲或算计的口吻出现，多为一两句，不展开。人物不长时间自我剖析，思绪常被外部事件打断。回忆以具体物件触发，例如残片、旧照、剑，不直接进入长段追叙。

**环境与地方感。** 样本支持且质量较高。特征是：环境描写带气味、声音、温度和旧物细节；地方感通过具体店名、街名、年代物件和方言建立；环境不是静态布景，常与人物状态互相映照，例如雨天、积水、尸体、雨伞；描写不追求全景，选取几个有质感的局部。

**情感爆发。** 样本中爆发场面不多，且处理克制。常见方式是：情绪先被压住，通过动作或沉默维持，然后在某个短句或动作上释放；释放之后不解释，直接切场景或让叙述停下来。作者不写长段情绪，不用感叹号堆叠。

**设定说明场景。** 样本支持。特征是：以问答形式展开，提问者是新手或外来者，回答者简短、不耐烦、只给必要信息；规则以条目或要点形式出现，但不写成条目化列表，而是嵌在对话里；说明中保留未解释部分，不用叙述者补充。

## 四、人物声音的区分方式

样本不靠固定口头禅区分人物，靠以下维度：

- **词汇范围**：有人用书面语和概念词，例如“制衡”“传承”“竞争”；有人只用生活词和动作词；有人用方言词和粗口。
- **句法完整度**：地位高或性格稳的人说话完整、有停顿、有转折；急躁或底层的人说话短、碎、省略主语。
- **是否解释自己**：有人习惯为自己的行为找理由，有人从不解释；有人反问，有人直接下结论。
- **对沉默的使用**：有人用沉默施压，有人用沉默回避；沉默在对话里的位置和长度本身是信息。
- **地域与身份标记**：方言混用、口音、称呼方式，例如“师兄”“太岁”“九哥”，标记关系和圈子。
- **说话时的身体动作**：有人说话时手不停，有人说话时完全不动；动作与内容的配合方式区分人物。

写作时不建议给人物设定口头禅或标志性句式。更有效的做法是先确定这个人在当前场景中的目的、他知道什么、他愿意暴露多少，再让他的说话方式从这三点里长出来。

## 五、有效写法与容易失效的反例

**有效写法（抽象）：**

- 用一个具体物件承载一段关系或一段过去，例如旧唱片、残片、剑、名片；物件被使用时，信息自然带出，不需要解释。
- 让人物在说话时做一件小事，例如倒水、抹鼻子、压子弹、抽烟；动作与台词形成反差或补充，情绪由此成立。
- 在暴力或转折前给一个日常细节，例如电视里的音乐、雨水、碗里的东西，让冲击落在具体环境里。
- 关键信息由弱势一方说出，强势一方用短句回应或沉默，权力关系不点明。
- 场景转换用地点或时间标记直接切开，不用过渡解释，读者自行接续。

**容易失效的反例（抽象）：**

- 把环境写成静态全景，列出所有街道、店铺和人物，却没有一个细节与人物发生关系；气氛因此停留在布景层面。
- 让人物用长段独白解释自己的动机和过去，把本该由动作和对话承担的信息集中成说明。
- 在打斗中逐招拆解、逐帧描写，读者失去对危险和速度的判断，场景变成动作说明书。
- 用感叹号、形容词堆叠和直陈情绪来制造爆发，例如连续写“他愤怒极了”“他心如刀割”，情绪反而变薄。
- 给每个人物配一个固定口头禅或标志性语气词，短期可辨，长期使人物变成标签。
- 把所有留白都补上，凡有暗示必给解释，凡有伏笔必在本章回收，文本失去呼吸感。
- 让叙述者替人物辩护或定性，例如“他其实是个好人”“这一切都是命运的安排”，人物的复杂性被旁白抹平。

## 六、写作时的使用原则

这份 Profile 描述的是样本如何产生效果，不是写作配额，也不是逐项验收表。使用时按以下原则：

1. **按场景选择，不按章节平均分配。** 不是每章都要有环境描写、内心独白、打斗和爆发；哪些手段出现，取决于这一章真正需要什么。日常章节可以整章没有冲突，冲突章节可以不写环境。

2. **信息延迟是默认，但不是禁令。** 该解释的地方要解释清楚，尤其是读者确实无法从上下文推断的关键规则。延迟是为了让信息在需要时出现，不是为了制造谜语。

3. **白描不等于不写情绪。** 克制是为了让情绪有落点，不是为了把人物写成没有感受的人。人物可以哭、可以怒、可以长篇说话，只要那是这个人物在这个时刻会做的事。

4. **人物声音优先于风格统一。** 如果当前人物的身份、教养、处境要求他说出与样本节奏不符的话，以人物为准。样本里的说话方式属于样本里的人物，不属于所有人物。

5. **不要复刻具体表达。** 样本中的句式、比喻、方言用法、称呼和意象属于该作品。可以用的是方法：用物件承载信息、用动作承载情绪、用对话承载权力关系、用短句控制节奏。方法可以迁移，句子不可以。

6. **文学需要高于特征统计。** 句长、段落长度、对白比例、标点频率都只是样本的偶然结果，不是目标。写作时如果某个场景需要长段、需要连续对白、需要华丽描写，就那样写。风格是结果，不是约束。

7. **样本不足处标注谨慎。** 本 Profile 对大规模战争、多线并行群像、长篇追叙、女性视角内部经验、非暴力冲突等类型的判断证据不足，样本中未充分出现，写作时不应把上面的场景描述硬套到这些类型上。遇到样本未覆盖的场景，按当前作品的文学需要处理，而不是向 Profile 求答案。

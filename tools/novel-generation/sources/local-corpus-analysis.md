# 本地全文语料与证据口径

最后更新：2026-11-05

## 语料

`original.txt` 由用户提供并保存在项目本地，作品为《从姑获鸟开始》（作者：活儿该）。文件 6,175,210 字节，118,089 行，去除空白后约 1,915,796 字。按章号重置切出 17 卷、753 章；末卷停在「第二十八章 此土佛法不足言（上）」，文本未完结。

这份语料与 `sources/public-chapter-sources.md` 记录的公开资料调查不是一回事。公开调查只保存书目元数据、卷名、章节标题和来源证据，不采集第三方站点正文；本地全文是用户自行提供、用于本地分析的文本，两者不交叉镜像，也不用本地全文去补造公开目录里缺失的标题。

## 使用边界

`original.txt` 与 `private/` 留在本地，不入库。`worlds/*/library/` 下的导入索引与抽取标注、`worlds/*/story-state.json` 随代码提交，其他机器检出后无需重新导入即可检索与续写。项目 `.gitignore` 目前只包含 `original.txt`、`private/`、`node_modules/`、`dist/`、`.output/` 和 `.env`。

`library/index.json` 保存的是按 1200 字切分、带 160 字重叠的全文片段，实质上是原文的重组副本。把它提交到版本库等同于把小说正文纳入版本库；若仓库公开，需确认所持文本的授权覆盖这种存储与分发。授权范围不足时，把 `worlds/*/library/` 加回忽略规则，只提交 `chapter-index.json` 等元数据。

交付的设定文档不复制章节正文。证据以 `L####` 行号定位，必要时保留极短引文（短语或单个句子），用于核对规则表述，不构成可替代阅读的摘录。新写的世界、规则和人物一律标注为项目原创。

## 切分与复现

`analysis/build-corpus-index.mjs` 从 `original.txt` 生成三份产物：

| 产物 | 内容 |
|---|---|
| `analysis/conghuoniao/chapter-index.json` | 卷、章、章号、标题、行号、字数；保留公开调查的章数差异说明 |
| `analysis/conghuoniao/corpus-profile.json` | 行数、字数、卷字数分布、术语频次、果实编号频次、卷间插入段 |
| `analysis/conghuoniao/volumes.md` | 卷结构对照表 |

章节标题正则允许行首缩进，因为全文有 30 个章节标题带空格或制表符缩进；只按行首严格匹配会把这些章并入前一章。`src/library.ts` 的 `HEADING` 已同步调整，`ingest` 重新导入后得到 2,594 个检索片段。章号按原文保留，二合一章节、补章和重复章号不做补齐，卷与卷之间的作者单章、卷末总结和感言计入 `corpus-profile.json` 的 `interludes`，不计入章节数。

```bash
cd tools/novel-generation
node analysis/build-corpus-index.mjs
npm run dev -- ingest --world conghuoniao --input ./original.txt
npm run dev -- search --world conghuoniao --query "龙虎气 觉醒度" --limit 5
```

## 证据等级

| 等级 | 含义 | 在设定文档中的用法 |
|---|---|---|
| 原著明确 | 正文、结算报告或系统面板直接给出的规则与数值 | 可作正史 |
| 作者设定 | 作者单章中的体系说明 | 可作正史，但不扩写未出现的层级 |
| 人物推断 | 角色根据有限信息作出的归纳、转述或猜想 | 只作角色认知，不作全书事实 |
| 项目原创 | 本工具新写的内容 | 与正史分开存放，不冒充原著 |

模型抽取式标注当前为空。`npm run dev -- analyze` 在本机限时 90 秒的试跑未返回抽取结果，也没有写出 `annotations.json`；全量 2,594 个片段逐片段调用模型不在这轮分析范围。人物状态时间序列、跨章节别名归并、共指消解和事件去重因此仍未实现，相关内容在设定文档里标为待核实。

## 核对过的差异

第一卷 42 章与公开目录一致；公开平台检索索引称全书 787 章，本地文本 753 章且末卷未完，差异保留为待核验项。卷 5 有 54 个章节标题而末章标为「第五十章」，卷 9、卷 14、卷 15 等也有类似现象，属于原文排版，不改动标题。

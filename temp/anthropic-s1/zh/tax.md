# 对美国境外持有人的重大美国联邦所得税后果

以下为若干美国境外持有人（定义见下文）就其在本次发行中取得的 A 类普通股的持有与处置所涉及的重大美国联邦所得税后果的概要，但并非旨在完整分析与之相关的所有潜在税务考量。本概要以截至本文件日期有效的《美国国内税收法典》（Code）规定、据此颁布的财政部条例、行政裁定与司法判决为依据。该等权威依据可能发生变化，且可能具有追溯效力，从而导致美国联邦所得税后果与下文所述不同。

本概要未涉及任何州、地方或美国境外司法辖区法律项下产生的税务考量，亦未涉及美国联邦非所得税法律（如赠与税与遗产税法）项下产生的税务考量，但下文所述有限范围除外。此外，本讨论未涉及适用于美国境外持有人特定情形或可能适用特殊税务规则的美国境外持有人的税务考量，包括但不限于：

- 银行、保险公司或其他金融机构（下文特别述及者除外）、受监管投资公司或房地产投资信托；
- 须缴纳替代性最低税或净投资收入医疗保险缴款税的人士；
- 免税组织或政府组织；
- 养老金计划或免税退休计划；
- 受控外国公司、外国受控外国公司、被动外国投资公司，以及为规避美国联邦所得税而累积收益的公司；
- 证券经纪商或交易商；
- 选择对其所持本公司股票采用按市值计价会计方法的证券交易商或其他人士；
- 拥有或被视同拥有本公司股本超过 5% 的人士（下文特别述及者除外）；
- 美国某些前公民或长期居民；
- 合伙企业或就美国联邦所得税目的被归类为合伙企业的实体或其他穿透实体（及其中的投资者）；
- 将本公司 A 类普通股作为对冲交易、“跨式”、“转换交易”或其他降低风险交易或综合投资头寸持有的人士；
- 因行使任何员工股票期权或其他作为补偿而持有或取得本公司 A 类普通股的人士；
- 因就本公司 A 类普通股的任何毛所得项目在“适用财务报表”（定义见 Code 第 451(b) 条）中确认而须遵守特殊税务会计规则的人士；
- 未将本公司 A 类普通股作为 Code 第 1221 条含义内资本资产（一般为持有用于投资的财产）持有的人士；或
- 根据 Code 推定出售条款被视同出售本公司 A 类普通股的人士。此外，若就美国联邦所得税目的被归类为合伙企业或其他穿透实体的合伙企业、安排或实体持有本公司 A 类普通股，则该合伙企业中的合伙人或该穿透实体中的所有者之税务处理一般取决于该合伙人或所有者的身份以及该合伙企业或其他穿透实体的活动。因此，持有本公司 A 类普通股的合伙企业及其他穿透实体，以及该等合伙企业中的合伙人和该等其他穿透实体中的所有者，应咨询其税务顾问。

**本讨论仅供信息参考，不构成税务建议。投资者应就美国联邦所得税法律对其特定情形的适用，以及购买、持有和处置本公司 A 类普通股在美国联邦非所得税法律（如赠与税或遗产税法）项下或任何州、地方、美国境外或其他征税辖区法律项下或任何适用税收协定项下产生的任何税务后果，咨询其税务顾问。**

## 美国境外持有人的定义

就本讨论而言，若投资者是本公司 A 类普通股的实益所有人，且不属于就美国联邦所得税目的被归类为合伙企业或其他穿透实体的合伙企业、安排或实体，并且就美国联邦所得税目的不被视为以下任何一类，则投资者即为美国境外持有人：

- 美国公民或居民的个人；
- 在美国或美国任何州或哥伦比亚特区法律下设立或组织的公司（或就美国联邦所得税目的被视为公司的任何其他实体）；
- 其收入不论来源均须缴纳美国联邦所得税的遗产；或
- （x）其管理受美国法院主要监督且有一名或多名“美国人”（含义见 Code 第 7701(a)(30) 条）（“美国人士”）有权控制该信托全部重大决定的信托，或（y）已作出有效选择被视为美国人士的信托。

**分配**

本公司 A 类普通股的分配，在从本公司当期或累积盈余与利润中支付的范围内，将构成美国联邦所得税目的下的股息，该等盈余与利润按美国联邦所得税原则确定。若该等分配超过本公司当期及累积盈余与利润，则超出部分将构成资本返还，并首先减少投资者在本公司 A 类普通股中的计税基础（但不低于零），其后按下文“——处置本公司 A 类普通股所得的收益”一节所述作为出售或其他处置股票的收益处理。

除下文关于有效关联所得的段落以及标题为“——备用预扣税与信息申报”和“——FATCA”的各节另有说明外，向投资者支付的任何股息一般须缴纳美国联邦预扣税，税率为股息总额的 30%，或美国与投资者居住国之间适用的所得税协定所规定的较低税率。根据适用的财政部条例，适用的预扣义务人可就全部分配总额按最高 30% 预扣，即使如上所述构成股息的部分低于该金额。若本公司或其他预扣义务人超额预扣，或投资者未及时向本公司提供所需证明，投资者可能有权通过及时向美国国税局（“IRS”）提交适当申请，就超额预扣的款项获得退还或抵免。

为适用协定规定的较低税率，投资者必须向适用的预扣义务人提供 IRS W-8BEN 表、IRS W-8BEN-E 表或其他适当版本的 IRS W-8 表，包括任何所需附件及投资者的纳税人识别号，以证明其符合适用较低税率的资格。此外，投资者须按法律要求不时更新该等表格与证明。若投资者依据所得税协定有权适用较低的美国预扣税率，可通过及时向 IRS 提交适当的退税申请，就任何超额预扣款项获得退还。若投资者通过金融机构或其他代其行事的代理人持有本公司股票，则须向该代理人提供适当文件，该代理人其后须直接或通过其他中介向本公司或本公司付款代理人提供证明。投资者应就享有任何适用所得税协定项下待遇的资格咨询其税务顾问。

投资者取得的、与其实施美国贸易或业务有效关联的股息（且若适用所得税协定要求，归属于投资者在美国维持的常设机构或固定基地的股息），一般免缴上述预扣税，但须遵守下文关于备用预扣税与 FATCA（定义见下文）预扣税的讨论。为取得该豁免，投资者必须向本公司提供 IRS W-8ECI 表，包括任何所需附件及投资者的纳税人识别号，以证明其符合该豁免的资格。此外，投资者须按法律要求不时更新该等表格与证明。该等有效关联股息虽无须缴纳美国联邦预扣税，但须计入投资者的美国联邦所得税申报表，并按适用于美国人士的相同税率向投资者征税，并扣除若干扣除项与抵免项。若投资者为公司型美国境外持有人，其取得的与实施美国贸易或业务有效关联的股息，还可能须按 30% 的税率或美国与投资者居住国之间适用的所得税协定所规定的较低税率缴纳分支机构利润税。投资者应结合其特定情形，就税收协定的适用咨询其税务顾问。

## 处置本公司 A 类普通股所得的收益

除下文标题为“——备用预扣税与信息申报”和“——FATCA”的各节另有说明外，投资者一般无须就出售或以其他方式处置本公司 A 类普通股所实现的任何收益缴纳美国联邦所得税，除非：

- 该收益与投资者实施美国贸易或业务有效关联（且若适用所得税协定要求，该收益归属于投资者在美国维持的常设机构或固定基地）；
- 投资者为在发生出售或其他处置的日历年度内在美国停留期间累计达 183 天或以上且满足某些其他条件的非居民外籍个人；或
- 由于本公司在投资者处置本公司 A 类普通股之前五年期间与其持有期两者中较短期间内的任何时候，就美国联邦所得税目的属于“美国不动产持有公司”（“USRPHC”），本公司 A 类普通股构成美国不动产权益，且在本公司 A 类普通股于成熟证券市场定期交易的情形下，投资者在上述期间内的任何时候拥有或被视同拥有本公司 A 类普通股超过 5%。

一般而言，若一家公司美国不动产权益的公允市场价值等于或超过其全球财产权益及用于或持有用于贸易或业务的其他资产的公允市场价值之和的 50%（均按美国联邦所得税目的确定），则该公司为 USRPHC。本公司认为，本公司目前不是、且未来也不会成为美国联邦所得税目的下的 USRPHC，本讨论的其余部分即以此假设为前提，但就此无法作出任何保证。若本公司目前是或未来成为 USRPHC，投资者应就由此可能对其产生的后果咨询其自身的税务顾问。

若投资者属于上述第一项所述美国境外持有人，则一般须就出售所取得的净收益按美国联邦所得税常规累进税率缴纳美国联邦所得税；且若投资者属于上述第一项所述公司型美国境外持有人，还可能须按 30% 的税率缴纳分支机构利润税；上述情形均以美国与投资者居住国之间适用的所得税协定另有规定者为限。若投资者属于上述第二项所述美国境外持有人，则一般须就出售或以其他方式处置本公司股票所取得的收益按 30% 的税率（或美国与投资者居住国之间适用的所得税协定所规定的较低税率）缴纳美国联邦所得税，该收益可用若干美国来源资本损失抵减（前提是投资者已就该等损失及时提交美国联邦所得税申报表）。投资者应结合其特定情形，就税收协定的适用咨询其税务顾问。

## 备用预扣税与信息申报

一般而言，本公司须每年向 IRS 申报向投资者支付的股息金额、投资者的姓名与地址以及已预扣税款（如有）。类似的申报表亦将发送给投资者。根据适用的所得税协定或其他协议，IRS 可能将该等申报资料提供给投资者居住国的税务机关。

向投资者支付的本公司 A 类普通股股息，或出售或以其他方式处置本公司 A 类普通股所得的款项，可能须进行信息申报并适用备用预扣税（目前税率为 24%），除非投资者证明豁免，例如通过在 IRS W-8BEN 表、IRS W-8BEN-E 表或其他适当版本的 IRS W-8 表上适当证明其美国境外身份。向适用预扣义务人提供的任何文件在某些情形下可能需要更新。

由任何美国或境外经纪商通过其美国办事处经办的本公司 A 类普通股出售或其他处置所得款项，一般须适用信息申报与备用预扣税，除非投资者证明其美国境外持有人身份并满足某些其他要求，或另行证明豁免。一般而言，若交易通过境外经纪商在美国境外经办，则向投资者支付的本公司股票出售或其他处置所得款项不适用信息申报与备用预扣税。然而，就信息申报目的而言，通过在美国拥有重大所有权或业务的经纪商的非美国办事处进行的出售或其他处置，一般将与通过经纪商美国办事处进行的出售或其他处置作类似处理。尽管有上述规定，若本公司或本公司付款代理人实际知悉或有理由知悉投资者为美国人士，则可能适用备用预扣税与信息申报。投资者应结合其特定情形，就信息申报与备用预扣税规则的适用咨询其自身的税务顾问。

备用预扣税并非额外税负。相反，须缴纳备用预扣税的人士的美国联邦所得税负债将按已预扣税款金额相应减少。若预扣导致税款超额缴纳，一般可向 IRS 申请退还或抵免，前提是及时向 IRS 提供所需信息。

**FATCA**

Code 第 1471 条至第 1474 条以及据此颁布的财政部条例与行政指引（统称“FATCA”）一般而言，对向“外国金融机构”（定义见 Code）支付的本公司 A 类普通股股息以及（在下文所述某些拟议财政部条例的约束下）出售或以其他方式处置本公司 A 类普通股的所得总额，按 30% 的税率征收美国联邦预扣税，除非财政部部长另有规定，或该机构与美国政府签订协议，约定对某些付款进行预扣，并向美国税务机关收集和提供有关该机构美国账户持有人（包括该机构的某些股权与债务持有人，以及某些由美国所有者拥有的非美国实体账户持有人）的大量信息，或另行证明豁免。FATCA 一般而言还对向“非金融外国实体”（定义见 Code）支付的本公司 A 类普通股股息以及（在下文所述某些拟议财政部条例的约束下）出售或以其他方式处置本公司 A 类普通股的所得总额，按 30% 的税率征收美国联邦预扣税，除非财政部部长另有规定，或该实体向预扣义务人提供证明，列明该实体某些直接和间接“美国重大所有者”（定义见 Code）并提供相关信息，证明其不拥有任何该等美国重大所有者，或另行证明并确认豁免。FATCA 项下的预扣规定一般而言适用于本公司 A 类普通股的股息。财政部部长已发布拟议条例，规定 FATCA 项下的预扣规定不适用于出售或以其他方式处置本公司 A 类普通股的所得总额，纳税人可在最终条例发布前依赖该拟议条例。美国与投资者税务居民国之间的政府间协定可能修改本段所述要求。投资者应就 FATCA 对其投资本公司 A 类普通股可能产生的影响咨询其自身的税务顾问。

**上述讨论仅供信息参考，不构成税务建议。每位潜在投资者应就购买、持有和处置本公司 A 类普通股所涉及的特定美国联邦、州、地方及非美国税务后果，包括适用法律任何拟议变更所产生的后果，咨询其自身的税务顾问。**

## Rule 144

一般而言，Rule 144 规定，在本公司受《证券交易法》第 13 条或第 15(d) 条规定的上市公司报告义务约束满 90 天之后，任何在出售前 90 天内任何时候均不被视为《证券法》项下本公司关联方、且已实益持有拟出售的本公司 A 类普通股至少六个月的人士，有权在不遵守 Rule 144 关于出售方式、数量限制或通知的规定的情况下出售该等股份，但须遵守 Rule 144 关于公开信息的要求。若该人士已实益持有拟出售股份至少一年（包括任何先前所有人（本公司关联方除外）的持有期），则该人士将有权在不遵守 Rule 144 任何要求的情况下出售该等股份。

一般而言，Rule 144 规定，本公司关联方或代本公司关联方出售本公司 A 类普通股的人士，有权在上述市场禁售协议与锁定协议届满后，在任何三个月期间内出售不超过以下两者中较高者的本公司 A 类普通股股数：

- 本公司届时流通在外股本股数的 1%，即本次发行完成后立即为（原文留白）股；或
- 就该项出售提交 Form 144 通知前四个日历周内本公司 A 类普通股的周平均交易量。

本公司关联方或代本公司关联方出售本公司 A 类普通股的人士依据 Rule 144 进行的本公司 A 类普通股出售，还须遵守某些出售方式规定与通知要求，并以本公司当前公开信息的可获得性为前提。

## Rule 701

Rule 701 一般而言允许依据书面补偿计划或合同购买本公司股本股份、且在紧接之前的 90 天内不被视为本公司关联方的股东，依据 Rule 144 出售该等股份，但无须遵守 Rule 144 关于公开信息、持有期、数量限制或通知的规定。Rule 701 亦允许本公司关联方依据 Rule 144 出售其 Rule 701 股份，而无须遵守 Rule 144 的持有期要求。但是，所有 Rule 701 股份持有人均须等到本招股说明书日期后 90 天，方可依据 Rule 701 出售该等股份。
